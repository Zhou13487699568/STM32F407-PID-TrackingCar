# STM32F407-PID-TrackingCar

基于 STM32F407 的双环 PID 循迹智能小车：编码器电机速度内环 + 循迹位置外环，配 OLED 状态显示与蜂鸣器报警。本项目是参赛作品《基于 PID 控制的焊缝勘测智能小车》的下位机控制工程。

> STM32F407 PID line-tracking smart car: encoder-based motor speed loop + track-following position loop, with OLED display and buzzer alarm.

## 功能特性

- ✅ 双电机 PWM 驱动（TIM1 CH1/CH2，20kHz）+ TB6612FNG 双 H 桥，支持正反转与差速转向
- ✅ 编码器接口模式测速：TIM4 / TIM5 硬件正交计数，TIM2 10ms 定时中断差分采样
- ✅ 通用 PID 控制器（`PID_TypeDef`）：输出限幅 + 积分限幅抗饱和，速度闭环
- ✅ 五路循迹传感器判线（TR1–TR5）：优先级去抖判线 + 偏差量化（中 0 / 内 ±1 / 外 ±2 / 脱线 999）
- ✅ 循迹位置外环（PD）：`Track_GetError()` 输出偏差 → 差速目标 → 速度内环
- ✅ 0.96" OLED（I2C1）实时显示速度 / PWM / PID 参数；蜂鸣器异常报警；按键交互
- ✅ `printf` 重定向 USART2，便于上位机调参与波形观测

## 硬件清单

| 模块 | 型号 / 规格 | 与主控接口 |
|---|---|---|
| 主控 | STM32F407（Cortex-M4，168MHz） | — |
| 电机驱动 | TB6612FNG 双路全桥 | TIM1 PWM + GPIO 方向 |
| 电机 | JGB37-520 直流减速电机 ×2（尾部霍尔编码器） | TIM4 / TIM5 编码器接口 |
| 循迹 | 5 路红外/灰度循迹模块（GPIO 数字输入） | GPIOD（TR1–TR5） |
| 显示 | 0.96 寸 OLED（SSD1306） | I2C1 |
| 报警 | 无源蜂鸣器（S8050 三极管驱动 + 续流二极管） | GPIO |
| 交互 | 按键 | GPIO |

## 控制架构

```
                 ┌────────────────────────────────────────┐
                 │            10ms 控制中断 (TIM2)          │
                 └────────────────────────────────────────┘
  循迹传感器 TR1~TR5 ──► Track_GetError() ──► 循迹外环（PD）
                                              │ 输出左右轮差速目标
                                              ▼
        ┌── 目标速度 ──► 速度内环 PID ×2（编码器反馈）──► TIM1 PWM ──► TB6612 ──► 电机
        │                   ▲                                    │
        └───────── TIM4 / TIM5 硬件正交计数，10ms 差分测速 ◄────────┘
```

- **速度内环**：编码器实时反馈轮速，PID 输出 PWM 占空比，保证左右轮速跟随目标（双轮差速即转向）。
- **位置外环**：循迹偏差经 PD 控制器映射为左右轮目标速度差，实现轨迹跟踪。

## 关键实现

- **通用 PID 结构体**：`PID_Init()` 一次配置 Kp/Ki/Kd、最大输出限幅与积分限幅（抗积分饱和），`PID_Calc()` 全浮点运算（FPU 加速）。
- **编码器测速**：定时器编码器接口模式硬件四倍频计数，10ms 中断内读取并清零计数器，差分得到瞬时轮速。
- **五路判线算法**：按“中间 → 内侧 → 外侧”优先级判断黑线位置并量化为 -2 ~ +2 的偏差值，全部未检出时置 999（脱线保护），避免误判抖动。
- **电机驱动**：正反转由 TB6612 的 AIN/BIN 电平组合控制，PWM 经绝对值取整后限幅输出。

## 实测指标（参赛整机）

| 指标 | 参数 |
|---|---|
| 循迹偏移 | ≤ 5 mm |
| 检测速度 | 0.1 – 0.5 m/s 可调 |
| 异常响应 | 缝隙检测 → 蜂鸣器声光报警 |

> 调试过程中使用逻辑分析仪抓取循迹信号波形，定位了模块电平毛刺导致的跳变问题，并通过硬件抗干扰优化解决；报警检测由轮询改为外部中断（EXTI）触发，显著加快响应速度。参赛版实物在此基础上将循迹模块升级为八路并改进加权算法。

## 目录结构

```
├── Core/                  # CubeMX 生成代码 + main（控制主流程）
├── Drivers/               # STM32 HAL 库
├── MDK-ARM/               # Keil MDK 工程
├── hardware/
│   ├── motor.c / motor.h          # TB6612 驱动（方向 + PWM）
│   ├── encode.c / encode.h        # TIM4/TIM5 编码器接口测速
│   ├── pid.c / pid.h              # 通用 PID 控制器（限幅 + 抗饱和）
│   ├── track.c / track.h          # 五路循迹判线与偏差计算
│   ├── oled.c / oled.h            # I2C OLED 显示
│   ├── beep.c / beep.h            # 蜂鸣器报警
│   └── key(new).c / key(new).h    # 按键
└── little_car.ioc         # STM32CubeMX 工程配置
```

## 编译与烧录

1. Keil MDK-ARM 打开 `MDK-ARM/` 下工程，或用 STM32CubeMX 打开 `little_car.ioc` 重新生成；
2. 编译烧录（SWD / ST-Link）；
3. 上电后小车进入速度环 + 循迹闭环运行，USART2 可接 USB-TTL 观察调参输出。
